# MediaRise — Landing Page

Site institucional da **MediaRise**, agência de tráfego pago e performance digital.
Especialistas em Google Ads, Meta Ads e landing pages de alta conversão.

🔗 **Tema:** performance / crescimento · **Stack:** HTML + CSS + JavaScript (sem dependências)

## ✨ Destaques

- Design premium "performance lab" (fundo obsidiana + verde-elétrico da marca)
- Totalmente responsivo (desktop, tablet e mobile)
- Animações em scroll, contadores animados, dashboard interativo e gauge de retenção
- Seções: Hero, Serviços, Método, Resultados, Diferenciais, Depoimentos, Planos, FAQ e CTA
- Botão flutuante de WhatsApp e menu mobile
- Logo e favicon vetoriais próprios
- SEO + Open Graph configurados

## 📁 Estrutura

```
MediaRise/
├── index.html          # estrutura da página
├── css/
│   └── styles.css      # estilos
├── js/
│   └── main.js         # interações
└── assets/
    ├── logo.svg        # logo (header/footer)
    ├── favicon.svg     # favicon vetorial
    ├── favicon-64.png  # favicon raster
    └── apple-touch-icon.png
```

## 🚀 Como usar

Basta abrir o `index.html` no navegador. Por usar apenas HTML/CSS/JS estático,
pode ser hospedado gratuitamente no GitHub Pages, Netlify, Vercel, etc.
